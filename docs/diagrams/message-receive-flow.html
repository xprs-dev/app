FIG 4 Where a notification fires, and where it cannot

Three common cases end in silence: no scope is ever emitted, no engine runs when the page is closed and autostart is off, and the announced-tag guard is permanent.

FIG 5 What stays the same about a message, and what does not

Dedup, receipts, custody release and reassembly all assume a message keeps one identity. Sealing is per attempt, so it does not.
